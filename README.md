# Landing — Dr. Vicente Monter Pérez

Vista previa de sitio estático en español para revisión visual y comercial. Optimizada para dispositivos móviles, con agenda externa y video del nuevo consultorio.

## Publicación gratuita con GitHub Pages

1. Crear repositorio público `dr.vicentemonter` en la cuenta `ocortesdiseno-mani` e inicializar con `README.md`.
2. Subir `index.html`, `aviso-de-privacidad.html`, `.nojekyll` y la carpeta `assets/` a la raíz de la rama `main` (o dejar que el asistente suba los archivos a través del conector GitHub).
3. En GitHub > Settings > Pages > Build and deployment, elegir **Deploy from a branch**, rama **main**, carpeta **/(root)** y guardar.
4. URL prevista, que solo funcionará tras confirmar despliegue: `https://ocortesdiseno-mani.github.io/dr.vicentemonter/`.

## Pendientes antes de activar Google Ads

- Validar título profesional, cédula, domicilio, teléfono, días y horarios y descripción de servicios con el doctor.
- Validar y completar el **aviso de privacidad**, actualmente borrador no apto como aviso definitivo; verificar el uso de Calendly y WhatsApp.
- Instalar Google Tag/GA4, Consent Mode (si corresponde) y un mecanismo fiable para medir citas **confirmadas**. Los clics en la agenda solo se prepararon como eventos `dataLayer` y no equivalen a citas.
- Revisar cumplimiento de Google Ads para salud, navegación móvil y formularios/cookies antes de pautar.
- Cambiar `robots` a `index,follow`, establecer dominio/canonical y comprobar propiedad en Search Console cuando el dominio sea definitivo.

No se publica información de pacientes en este paquete. El video y el logotipo son del material provisto para el proyecto.
